# Kranz 0.9.0

Kranz 0.9.0 lets a coding agent join the local runtime already open in your
TUI. The agent can inspect the same services, read bounded logs, run actions,
restart a service, and wait for readiness. There is no second stack and no
hidden daemon; disconnecting an attached agent leaves your session running.

- **One runtime:** TUI, CLI, and MCP use the same supervisor.
- **One view of the project:** selectors, action runs, plans, and logs share the
  application contract.
- **Clear ownership:** an attached MCP disconnect leaves the stack running;
  owner fallback performs managed cleanup.

The first release uses local foreground stdio and ships in the existing
`kranz` binary. It does not add a daemon, remote transport, arbitrary command
execution, interactive actions, or external PID control.
